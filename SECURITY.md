# Security Policy

## Supported versions

Only the latest stable release receives security fixes.

## Reporting a vulnerability

Do not report security vulnerabilities through public issues.

Use the repository's **Security** tab to submit a private vulnerability report through GitHub Security Advisories. Include:

- the affected version
- the operating system and Node.js version
- the installation scope (`project` or `global`)
- clear reproduction steps
- the files or settings affected
- the expected and actual behavior

Avoid including real access tokens, credentials, private configuration, or unrelated project source code.

The report will be reviewed privately before any public disclosure or release notes are prepared.
